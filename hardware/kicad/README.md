# Projeto Eletrônico KiCad 8.0 — AEGIS-MECH S3

- **Esquemático:** `aegis_mech_s3.kicad_sch`
- **Layout PCB:** `aegis_mech_s3.kicad_pcb` (4 Camadas: F.Cu, In1.Cu GND, In2.Cu Power, B.Cu)
- **Regras DFM:** JLCPCB 4-Layer Standard (trilhas mínimas 0,2 mm sinal, 2,5 mm potência, furos via 0,3 mm).
- **Testpoints Mapeados:** TP1 (+12V Fused), TP2 (+5V Bus), TP3 (+3V3 Dig), TP4 (GND Star), TP5/TP6 (I2C SDA/SCL), TP7 (ECHO 3,23V), TP8 (Shunt INA219).
