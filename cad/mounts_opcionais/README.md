# Suportes Opcionais STL / CAD

Modelos complementares para as expansões do sistema:
- `camera_mount_esp32cam.scad`: Suporte vertical para ESP32-CAM (Expansão C1 Visão 2FA).
- `wand_enclosure_esp32c3.scad`: Caixa ergonômica da Varinha Gestual ESP-NOW com MPU6050 (Expansão C2).
- `tray_mount_2dof.scad`: Mancal e braço articulado para gaveta motorizada 2-DOF / SO-ARM100 (Expansão D).
